# 01: 高耸多回路铁塔横担扫描下延与跳线门槛放宽 (TallMultiCircuitLowerBoundary)

**What to build:**
解决 18-19# 等高耸多回路铁塔（塔净高 >= 45m）最下层横担漏识别导致蓝黄分割线偏高腰斩的问题。
将输电铁塔横担候选切片初筛起始门槛从硬编码的 50% 塔高统一降为 35% 塔高（结合 12m 绝对防树物理底线），并同步将耐张跳线高度限制下放至 35% 塔高。
实现最底层横担被完整注册识别，蓝黄分割线 `abs_z_boundary` 精准下沉至最底层横担下方 1.5m~3.0m 纯净塔腰。

**Blocked by:** None (can start immediately)

**Status:** closed

- [x] `min_search_z = max(max_z * 0.35, min_arm_floor)` 在高耸大铁塔上能够向下检索到 35% 塔高处的横担切片。
- [x] `is_tension_jumper` 的判定高度门槛调整为与扫描下限匹配（`z_c >= max_z * 0.35`）。
- [x] 在 18-19# 塔 2（68m 高塔）上，最下层横担（`rel_z ≈ 31.2m`，`abs_z ≈ 49.2m`）成功被检测为最低横担，`abs_z_boundary` 稳定下沉至约 42.4m（最下层横担下方）。
- [x] 低于 35m 的常规铁塔由于受到 12m 绝对防树底线保护，起始扫描高度绝不落入低空地表树冠，不引入任何低空林木误报。
