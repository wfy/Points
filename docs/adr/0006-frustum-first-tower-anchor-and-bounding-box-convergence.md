# 0006. Frustum-First Tower Anchor, Single-Orientation Alignment, and Physical Proportion Guard

## Status
Accepted

## Context
在实测 `0-1(0_1).las`、`5-6(5_6).las` 与 `68-69(68_69).las` 过程中，铁塔二段式几何收敛遭遇了三类由“自顶向下（Top-Down）估算”引发的深层次几何断裂：
1. **高空非对称拉偏塔心（68-69#）**：转角塔或单侧出线塔的横担外展极其不对称（实测一侧 16.6m，另一侧仅 3.3m）。原算法在 55%~80% 塔高处以点云均值计算中心，导致塔心被向单侧拉偏达 3.8m。中轴偏离后，下塔身立柱与四棱台完全脱节；
2. **两塔先验误导主轴、45° 对角线错位（5-6#）**：转角耐张塔由于横担沿转角平分线布置，与两塔直线跨档方向存在夹角。先验锁定机制在比对正交投影时，错误锁定了塔脚 4 根腿的 45° 对角线（34.3°），导致下部四棱台以菱形斜切正方形塔身，俯视图中黄蓝包围盒呈严重剪刀差；
3. **大塔自然放坡角钢冒充横担梁、分界线下坠（68-69#）**：56m 大塔在 16m 处立柱半宽已自然放坡扩展至 8.1m，满足了粗糙的 `w1 >= 5.0m & w1 - w2 >= 2.0m` 判据，横担分界线一路雪崩坠落至 14m（上部占比高达 97%），下半身角钢几乎全部漏识；
4. **上部长方体顺线厚度硬编码外溢吞导线（0-1#）**：顺线半厚度设死 5.5m 下限，且横担半宽冗余外推 18%，导致非挂点出线导线被卷入上部 OBB 盒。

## Decision
我们正式确立**“四棱台自底向上定姿（Frustum-First Anchor）+ 单一刚体朝向对齐 + 物理几何比例熔断（Physical Proportion Guard）”**的铁塔几何收敛升级规范：

1. **四棱台自底向上基准定姿 (`Frustum-First Anchor`)**：
   - 彻底摒弃在高位横担/导线混杂区计算塔心的做法；
   - 统一在近地纯净塔腰四棱台区间（`z ∈ [max(5.0, 0.15*H), max(18.0, 0.40*H)]`）提取 4 根主腿角钢；
   - 以 4 根主腿外接/内切矩形的对角线交点作为全塔唯一且不可动摇的物理轴心 $(c_x, c_y)$；
   - 以 4 根主腿围成的正方形外立面正交向量作为铁塔基准朝向 $(\vec{v}_1, \vec{v}_2)$。

2. **单一刚体朝向对齐 (`Single-Rigid-Orientation`)**：
   - 上半部 UpperTowerBox 与下半部 LowerTowerFrustum 严格共享相同的正交主轴 $(\vec{v}_1, \vec{v}_2)$；
   - 矩形体包围盒的朝向严格锁定为铁塔物理朝向，杜绝转角塔下半身菱形倾斜与剪刀差。

3. **物理几何比例熔断 (`Physical Proportion Guard`)**：
   - **刚性物理下限**：最下层横担基准高程 $z_{\text{lowest\_arm}}$（`WaistBoundaryElevation`）刚性下限为全塔净高的 **30%**（即 $z \ge \max(0.30 \times H,\ 10.0\text{m})$），低于此高度一律禁止作为横担层；
   - **阶跃突变判定 (Derivative Edge Detection)**：真正的横担悬臂相对于下层塔腰必须具有明显的几何展宽突变（$\Delta w \ge 2.5\text{m}$ 或 $w_{\text{span}} / w_{\text{trunk}} \ge 1.8$），平滑线性放坡的塔腿角钢坚决排除。

4. **UpperTowerBox 紧致收敛与非连接导线阻断**：
   - 废除顺线厚度 $5.5\text{m}$ 的生硬硬编码下限；
   - 顺线半厚度紧密贴合绝缘子挂点物理界限（约束在 $3.0\text{m} \sim 3.8\text{m}$）；
   - 横担半宽取消 18% 过度外推，采用紧致的分位数加制造安全裕量，确保上部矩形体自然阻断外侧跨中导线。

## Consequences
- 彻底解决不对称横担拉偏塔心、转角塔对角线 45° 错位、大塔横担分界线下坠的三大系统性缺陷。
- 保证铁塔上部为纯正、紧致的矩形体包围盒，出线侧非连接导线被干净剔除。
- 建立符合土木工程物理常识的几何熔断防御机制。
