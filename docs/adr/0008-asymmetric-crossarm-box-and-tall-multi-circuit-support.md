# 0008. Asymmetric Crossarm Box, Tall Multi-Circuit Lower Boundary, and Adaptive Frustum Slope

## Status
Accepted

## Context
在实际输电线路工程多场景点云（包括 5-6#、18-19#、0-1# 等）分类成果验证中，暴露出三处严重的几何包围盒先验失真缺陷：
1. **耐张转角塔单侧大弧垂跳线被误切 (5-6# 图 1)**：
   原逻辑基于“铁塔横担必须绝对双侧对称”的强假设，在 `w_max > w_min * 1.25 + 0.5` 时强行将宽侧削弱至窄侧水平（`w_sym_cap = w_min * 1.05 + 0.3`）。然而，大转角耐张塔受力非对称，外侧存在外伸达 9m~10m 的大弧垂跳线与金具，而内侧耐张绝缘子串顺走廊拉紧（横担向仅展宽 2m~3m），导致算法误将外侧数千个真实跳线点削为背景植被（绿色）；
2. **超高四回路多层横担铁塔蓝黄分割线偏高 (18-19# 图 2)**：
   原逻辑设定横担扫描起始比例为 `min_arm_ratio = 0.50`，在 68m 等超高多回路铁塔上起始高度高达 34.0m（绝对高程 52.0m），直接跳过了位于 45% 塔高处（绝对高程约 49.2m）的第 4 层最下层横担，导致分割线落在第 3 与第 4 层之间，最下层横担躯干被涂黄、横担双翼被下半截四棱台削为绿色；
3. **下半部四棱台放坡过紧与陡坡塔脚漏识 (0-1# 等)**：
   原逻辑将放坡率硬编码死锁在 `max_slope_rate = 0.075`（1:13.3 极陡坡），且下半部 3D CC 空间连通半径仅为 `0.85m`，在耐张大开度塔或山地林区稀疏角钢处导致连通断裂，大范围塔靴和下部斜材被误剔除。

## Decision
我们正式确立**“双侧非对称横担定向盒 (AsymmetricCrossarmBox) + 高耸多回路横担扫描下延 (TallMultiCircuitLowerBoundary) + 自适应放坡与陡坡连通性增强 (AdaptiveFrustumSlope)”**的三维几何重构技术规范：

1. **双侧非对称横担定向盒 (`AsymmetricCrossarmBox`)**：
   - 彻底废除“宽侧必须被窄侧硬剪截断”的强制双侧对称假设；
   - 对横担轴向正负两翼分别度量实际外展 `w_pos` 与 `w_neg`，构建左右各自独立的半宽边界 `half_arm_pos = min(w_pos + 0.35, half_arm_max * 1.10)` 与 `half_arm_neg = min(w_neg + 0.35, half_arm_max * 1.10)`；
   - 防御山坡树木拉偏的责任从粗暴的几何强制截断完全移交至现有的 `UpperTowerBox 3D CC`（自塔身种子体素向外三维连通扩散），不连通的悬空树冠被拓扑连通性物理阻断。

2. **高耸多回路横担扫描下延 (`TallMultiCircuitLowerBoundary`)**：
   - 将横担扫描比例门槛由 `min_arm_ratio = 0.50` 统一放宽至 `0.35`，同时坚守 `min_arm_floor = 12.0m` 的绝对防树底线（`min_search_z = max(max_z * 0.35, 12.0)`）；
   - 同步将 `is_tension_jumper` 的判定高度门槛由 `z_c >= max_z * 0.60` 放宽至 `z_c >= max_z * 0.35`；
   - 确保超高多回路铁塔的最下层横担及耐张跳线被完整捕获，蓝黄分割线 `abs_z_boundary` 精准落位在最底层横担下方 1.5m~3.0m 纯净塔腰。

3. **自适应放坡与陡坡连通性增强 (`AdaptiveFrustumSlope`)**：
   - 放开四棱台最大放坡斜率上限至 `max_slope_rate = 0.15`（支持 1:6.7 大开度塔腿），恢复基础塔基裕量 `margin_val = 0.80m`；
   - 下半部 3D CC 空间连通搜索半径由 `0.85m` 放宽至 `1.20m`，容纳林区扫描角钢稀疏点断裂；
   - 下部有效高程由 `z_ground_datum - 3.0` 扩展至 `-8.0m`（或地面网格最低非地面点），容纳山地大高差长短腿塔。

## Consequences
- 5-6# 等耐张转角塔外侧大弧垂跳线与金具 100% 完整检出为铁塔（蓝色），跳线漏识别率降至 0。
- 18-19# 等超高四回路铁塔最下层横担被完整识别，蓝黄分割线准确下沉至最底层横担下方，横担两翼完好保留为铁塔。
- 0-1# 等山地陡坡塔下部塔脚点云完整检出（黄色），彻底消除“下部收敛过紧削去塔脚”的缺陷。
- 全量自动化测试（81+ tests）与物理点云验证回归通过，杜绝任何精度与拓扑退化。
