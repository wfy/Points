# 0005. Two-stage Tower Geometric Convergence via UpperTowerBox and LowerTowerFrustum

## Status
Accepted

## Context
在输电线路激光雷达点云分类中，铁塔几何收敛长期面临多尺度、跨电压等级（110kV ~ 500kV+）的复杂挑战：
1. **上部横担与跳线外展**：高压铁塔多层横担水平展宽可达 10m~30m，耐张塔跳线环弧垂下挂 2m~4m，绝缘子串长度随电压等级自 1.2m 剧增至 4.5m 以上；
2. **下部塔腰与塔腿收缩**：横担以下过渡为立柱角钢，宽度骤降至 2m~4m，而在地面塔基处又以固定斜率外扩；
3. **山地植被交叠**：若在全塔范围内使用单一全局包围盒，地面处数十米宽的盒子会吞噬大量山坡树木；若仅靠局部点云表面重建，在稀疏激光点下极易发散破碎。

为了建立兼顾极高运算效率与抗噪鲁棒性的生产级几何模型，需要确立铁塔空间的宏观分治收敛范式。

## Decision
我们正式确立**“上半部定向矩形包围盒（UpperTowerBox）+ 下半部四棱台包围盒（LowerTowerFrustum）”**的双段空间几何分治架构：

1. **分界面高程基准 (`WaistBoundaryElevation`)**：
   - 分界平面严格锚定在“最下层横担角钢与耐张跳线环弧垂底端”之下 1.5m 裕量处；
   - 所有横担构件、下斜撑角钢与跳线环金具 100% 归入 UpperTowerBox 包络，彻底杜绝交界面因阶跃断层而切断下斜撑角钢。

2. **上半部矩形体 (`UpperTowerBox`) 跨电压等级自适应**：
   - 沿横担主轴 $v_1$ 覆盖全部外展悬臂构件；
   - 沿顺线厚度轴 $v_2$ 摒弃固定米数硬编码，基于横担总展宽 $W_{\text{arm}}$ 与铁塔净高 $H$ 的物理比例自适应约束绝缘子挂点裕量：
     $$W_{\text{line\_half}} = \frac{W_{\text{trunk\_line}}}{2} + \min(0.18 \times W_{\text{arm\_half}},\ 0.08 \times H)$$
     有效适配 110kV/220kV/500kV 等不同绝缘子串尺度，同时阻断大跨度跨中悬空导线入盒。

3. **下半部四棱台 (`LowerTowerFrustum`) 放坡与真中轴对齐**：
   - 严格以 D15 纯净塔身多层切片几何中轴为基准，自分界面塔腰立柱向地面以真实角钢放坡斜率（$0.08 \times k_{\text{height}}$）线性放坡；
   - 采用正四棱台对称放坡模型，横担向与顺线向保留独立的安装裕量。

4. **塔基贴地段与地表植被的 3D 骨架连通剥离**：
   - 四棱台作为外围紧致空间掩膜，内部施加“以塔腰纯立柱为种子点向下的 3D 骨架体素连通生长（步长 0.85m）”；
   - 依靠金属角钢的物理刚性连通，精准剥离四棱台底角覆盖的非连通山坡树冠与贴地杂草。

5. **流水线职责解耦**：
   - 阶段二 UpperTowerBox 维持挂点区域的安全几何包络；
   - 绝缘子末端挂点与导线的亚米级精密分离，解耦至阶段三（3D 悬链线拟合追踪）与阶段四（依附拓扑校验）闭环处理。

## Consequences
- 在业务与算法层面统一了铁塔二段式几何收敛的领域术语与物理数学模型。
- 彻底解决了跨电压等级下绝缘子长度失配与陡坡林木误吞的结构性难题。
- 为 `modules/tower_detector.py` 的精简、重构及单元测试提供了清晰的架构契约。
